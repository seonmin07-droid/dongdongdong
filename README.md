# Spec-Check AI 프로젝트

## 폴더 구성
- `index.html`: 웹사이트 시작 파일
- `css/style.css`: 화면 디자인 및 반응형 스타일
- `js/app.js`: 화면 전환, 프로젝트 목록, 스펙체크 등 동작 코드
- `data/spec_check_projects.json`: 제공된 프로젝트 데이터
- `asset/`: 이미지·아이콘 등 정적 리소스 보관 위치
- `pages/`: 향후 페이지별 HTML 파일을 분리할 때 사용할 위치

## 실행 방법
1. ZIP 압축을 해제합니다.
2. `index.html`을 브라우저에서 엽니다.
3. 모바일 화면에 맞춰 제작된 웹앱이므로 브라우저 개발자 도구의 모바일 보기에서도 확인할 수 있습니다.

## 참고
현재 업로드된 원본은 단일 페이지(SPA) 구조입니다. 따라서 기존 화면과 기능을 유지하면서 CSS와 JavaScript를 각각 `css/`, `js/`로 분리했습니다. 화면별 HTML은 원본에서 별도 파일로 분리되어 있지 않아 `pages/`는 후속 페이지 분리를 위한 폴더로 마련했습니다.
프로젝트 데이터 JSON은 요청한 `data/` 폴더에 원본 파일 내용을 유지해 배치했습니다. 앱 내부의 예시 프로젝트 목록은 원본 JavaScript에 포함된 상태이며, JSON 파일은 별도 데이터 원본으로 제공됩니다.
