# Spec-Check AI

**현재 버전: v0.4**

## 프로젝트 소개
생성형 AI·바이브코딩으로 개발하는 사용자가 요구사항과 코드 등록 결과를 점검하고, 다른 사용자의 공개 스펙을 참고할 수 있도록 지원하는 모바일 우선 웹 프로토타입입니다.

## 폴더 구성
- `index.html`: 웹앱 화면 및 화면 구조
- `css/style.css`: 디자인 및 반응형 스타일
- `js/app.js`: 화면 전환, 프로젝트 카드, 회원 상태, 스펙체크 동작
- `data/spec_check_projects.json`: 프로젝트 데이터 파일
- `asset/`: 이미지·아이콘 등 정적 리소스
- `pages/`: 향후 페이지별 HTML 분리용

## 실행 방법
1. ZIP 압축을 해제합니다.
2. `index.html`을 브라우저에서 엽니다.
3. 모바일 우선 웹앱이므로 필요하면 개발자 도구의 모바일 화면으로 확인합니다.

## v0.4 세부 동작
- 탐색의 각 프로젝트 카드에서 `스펙체크 하기`를 누르면 선택한 프로젝트의 명세를 스펙체크 화면으로 가져옵니다.
- 가져오는 항목은 프로젝트명, 목적, 도메인, 프로그래밍 언어, 요구사항입니다. 기존 사용자의 코드가 섞이지 않도록 코드 입력은 비운 상태로 시작합니다.
- 마이페이지는 비로그인 상태에서 로그인 버튼만, 로그인 상태에서 로그아웃 버튼만 표시합니다.
- 하단 내비게이션은 홈 / 탐색 / 마이페이지 3개입니다.

## 구현상 한계 및 확인 사항
- 현재 회원 기능은 브라우저 로컬 저장소 기반 데모 계정 흐름이며, 실제 보안 인증과 다중 기기 동기화는 별도 백엔드가 필요합니다.
- 공개 프로젝트와 좋아요를 모든 사용자·기기에서 공유하려면 공용 서버 저장소/API가 필요합니다.
- 현재 코드 분석은 패턴 기반 데모이며, 코드 실행이나 의미 기반 요구사항 충족을 보증하지 않습니다.
- `data/spec_check_projects.json`과 앱 내부 예시 프로젝트 배열이 별도로 존재하므로, 향후 단일 데이터 원본으로 통합할지 결정이 필요합니다.
